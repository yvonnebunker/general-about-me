Current Class Overview

SEC 230: Introduction to Linux

Most of the internet and the vast majority of security tools run on Linux. Learning this operating system will give the foundational skills needed to navigate servers, analyze system logs, and understand how environments operate internally.

MAT 200: Pre-Calculus

Security is, fundamentally, about logic and problem-solving. This math course will strengthen analytical thinking and general mathematical understanding, which are important tools when you start breaking down complex code or algorithms.

SEC 290: Intro to Programming with Python

Automation is important in almost all aspects of technology now, including modern defense. In cybersecurity, Python is used to write quick scripts that automate repetitive tasks and analyze massive amounts of security data in seconds. Automation and proper incident detection are vital areas of cybersecurity.
